# Мини-приложение VK для получения пользовательского ключа

Зачем: ключ сообщества умеет только публиковать текст (фото, чтение стены и статистика
для него закрыты). Пользовательский ключ открывает полную автоматику. Чтобы получить его
без сторонних сервисов, используем **своё** мини-приложение на бесплатном хостинге.

## Что понадобится

- аккаунт GitHub (бесплатный);
- домен `mirosvod.ru`, купленный в TimeWeb (доступ к DNS-записям);
- ничего платного и никаких серверов.

## Шаг 1. Репозиторий и страница

1. На GitHub создайте **публичный** репозиторий, например `vk-token` (публичный нужен,
   потому что GitHub Pages на бесплатном тарифе работает только для публичных репозиториев;
   секретов в этой странице нет — только код, который показывает ключ).
2. Загрузите в него `index.html` из этой папки.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)` → Save.
4. Через минуту страница будет доступна по адресу `https://<ваш-логин>.github.io/vk-token/`.

## Шаг 2. Свой поддомен (по желанию, но красиво)

1. В TimeWeb в DNS-записях домена `mirosvod.ru` добавьте запись:
   - тип `CNAME`, имя `vk`, значение `<ваш-логин>.github.io`.
2. В GitHub: Settings → Pages → Custom domain → `vk.mirosvod.ru` → Save,
   затем включите `Enforce HTTPS` (сертификат GitHub выпустит сам).
3. Итоговый адрес приложения: `https://vk.mirosvod.ru/`.

Если DNS-редактор TimeWeb не даёт поставить CNAME на apex-домен, поддомен `vk` — рабочая схема.

## Шаг 3. Приложение в VK

1. `dev.vk.com` → «Приложения» → «Создать приложение» → тип **Мини-приложение**.
2. Название: `orchestrai` (или любое), категория — по вкусу.
3. В настройках укажите **базовый адрес**: `https://vk.mirosvod.ru/` (или адрес GitHub Pages).
4. Скопируйте **ID приложения** (число) — он нужен, чтобы открыть приложение.
5. Приложение можно не публиковать в каталоге: достаточно, что вы его владелец.

## Шаг 4. Получение ключа

1. Откройте `https://vk.com/app<ID>` в браузере, где вы вошли в VK.
2. Нажмите «Получить ключ» → VK спросит разрешение с правами
   `wall, photos, groups, offline` → «Разрешить».
3. Страница покажет ключ и кнопку «Скопировать в буфер».
4. Положите ключ в KeePassXC записью **`Токен ВК Технарь пользовательский`**
   (поле «Пароль»), закройте страницу.

## Шаг 5. Перенос в защищённое хранилище

В своём окне PowerShell 7:

```powershell
cd "C:\Users\oom33\Проекты\Мои\мультиагентная-платформа-dsh\проект-DSH\секреты"
.\экспорт-токена.ps1 -Entry "Токен ВК Технарь пользовательский" -Name vk-token-user
```

Скрипт спросит мастер-пароль базы (скрыто), заберёт ключ по трубе, проверит формат,
зашифрует через DPAPI и напечатает только путь, длину и `sha256[:12]`.

## Безопасность

- ключ действует от вашего имени — права минимальные: `wall, photos, groups, offline`;
- `messages`, `friends`, `notify` **не запрашиваются**;
- хранение — только DPAPI текущего пользователя, файл с правами «владелец + SYSTEM»;
- отзыв в один шаг: смена пароля VK или «Завершить все сессии» в настройках безопасности;
- страница ничего никуда не отправляет: ключ остаётся в окне браузера.
